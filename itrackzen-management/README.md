# ITrackZen Management System

Odoo 18.0 Community with ITrackZen add-ons, opened from the ITrackZen website admin area by single sign-on.

- `addons/` the ITrackZen add-ons (`itz_*`)
- `deploy/` install script, nginx, systemd, backup and restore scripts
- `integration-layer/` mock tracking platform for testing the connection
- `docs/` start with [docs/README.md](docs/README.md), then [docs/INSTALL.md](docs/INSTALL.md)

The website with the single sign-on bridge is in `../itrackzen-website/`.
