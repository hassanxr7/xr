## Hufan Exchange — money exchange website (PHP / MySQL)

The [`exchange/`](exchange/) folder contains a complete money exchange platform
(EVC Plus → MoneyGo · USDT · PayPal) with printable statements and receipts and a full admin panel.
It is built for Hostinger Shared Hosting — see [`exchange/README.md`](exchange/README.md) for installation.

## The Guardia — news website

The [`theguardia/`](theguardia/) folder contains a complete news website for **theguardia.ca**: a responsive public site with strong SEO (news sitemaps up to 50,000 URLs each, structured data, IndexNow), a bilingual (English/Somali) newsroom dashboard with an AI writing assistant, an AI newsroom (Alex, Kristov Joi, David Mario), analytics by hour/day/month/year, country, city and traffic source, push notifications, Google AdSense, a photo store for media outlets, and importers for official court records. It runs on Hostinger shared hosting (PHP + SQLite). See [`theguardia/README.md`](theguardia/README.md).
